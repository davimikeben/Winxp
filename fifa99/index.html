Rode FIFA 99 no navegador

Emulador de Nintendo 64 compilado para WebAssembly, rodando dentro da aba. A ROM e lida direto do seu disco: nenhum byte e enviado para servidor.

📁 Arraste a ROM aqui ou toque para escolher · .z64 / .n64 / .v64 / .zip

Verificando suporte do navegador...

SharedArrayBuffer indisponivel. O core vai rodar em modo single-thread (mais lento, com quedas de quadro). Para liberar o modo multi-core, sirva a pagina pelo server.js deste projeto (ele envia os headers Cross-Origin-Opener-Policy e Cross-Origin-Embedder-Policy) ou publique em um host que permita configurar esses headers.

Como usar

  1. Escolha o arquivo FIFA 99 (USA) (...).z64.
  2. Confirme os dados do header na ficha que aparece.
  3. Toque em Iniciar partida e aguarde o menu do jogo.

Salvar progresso

  • O app injeta um Controller Pak no slot 1, entao o save interno do FIFA 99 funciona.
  • O menu do emulador tambem tem save state instantaneo (rapido e independente do jogo).

Requisitos

  • Navegador com WebAssembly + WebGL (Chrome, Edge, Firefox, Safari 16+).
  • ~50 MB de RAM livre e um dispositivo com CPU razoavel (o N64 e emulado por software).
  • Headers COOP/COEP para o modo multi-thread — ja configurados no server.js.

Nota legal

Este projeto entrega apenas o runtime (emulador WASM + interface). A ROM de FIFA 99 e propriedade da EA Sports / Nintendo e nao esta incluida. Use somente um dump que voce mesmo extraiu do seu proprio cartucho.
